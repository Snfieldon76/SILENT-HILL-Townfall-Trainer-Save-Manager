## 🧰 Troubleshooting Common Issues

**Issue: The app doesn't detect my save files.**
Make sure your game is installed on the same drive where you run the manager. Also ensure you've launched the game at least once so save files exist. If issues persist, go to Settings > "Save Folder" and manually select the folder where your saves are located (usually under `Documents\My Games\Silent Hill Townfall\Saves` or similar).

**Issue: The app won't open / crashes on startup.**
Verify your Windows is updated. The app requires .NET Framework 4.8 or higher — if you don't have it, Windows will typically prompt you to install it automatically. Restart your PC after installation and try again.



**Issue: FOV changes don't apply in the game.**
